# docs-user-audit

## Por qué

El propietario pidió auditar la documentación pública para usuarios, retirar narrativa interna y
completar inglés y español. Las guías mezclan instrucciones vigentes con investigación, fases,
procedimientos de publicación y comprobaciones históricas. El portal produce avisos de idioma en
lugar de traducciones y usa el README de contribución como portada del producto.

## Cambio autorizado

Vía rápida documental: revisar las trece guías conservadas contra sus fuentes, corregir las
instrucciones y límites, agregar traducciones e índices de producto EN/ES y verificar sus enlaces.
No cambia comportamiento, dependencias, credenciales ni publicación. El propietario autorizó
expresamente esta auditoría; no hace falta otro issue para repetir esa autorización.

## Fronteras

No modifica la constitución, el rumbo ni `meltemi.md`. No ratifica enmiendas pendientes ni archiva
`docs-en-el-sitio`, `lanzador-conversacional` u otro cambio con gate fundacional. Se conservan las
rutas e idiomas canónicos actuales y se añaden traducciones, sin declarar una lengua fuente nueva.
El conversor y la publicación del portal pertenecen a Meltemi Web.
