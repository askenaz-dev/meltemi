# Meltemi IDE documentation

[Español](es/README.md)

Run the coding agents you already use, follow their work, answer permission requests and review
changes from the desktop app or terminal. Meltemi runs on your machines, with no Meltemi account
and no telemetry. Each agent uses its own authentication and model.

## Start

- [Quickstart](quickstart.md): install, check the connection and start your first session.
- [Free sessions](sesion-libre.md): send instructions, follow turns, decide permissions and use
  the restore point without creating a specification first.

## Agents and project context

- [Agents](agentes.md): find an installed agent, repair a missing layer and select a profile.
- [Local and self-hosted models](local-models.md): connect a model through your agent's settings.
- [Shared instructions with the harness](harness.md): write rules once and see which ones apply.
- [The SDD method](metodo-sdd.md): propose, plan, review, implement, verify and archive a change.

## Machines and accessibility

- [Remote access](en/acceso-remoto.md): connect over your SSH, supervise work and answer from
  another machine or a phone.
- [Platforms](plataformas.md): supported installers, data folders and environment settings.
- [Accessibility](accesibilidad.md): plain output, JSON, ASCII and reduced motion.

## Reference and troubleshooting

- [CLI reference](referencia-cli.md): commands, flags and exit codes from the installed client.
- [Questions and troubleshooting](faq.md): start with `meltemi doctor` and find the next step.
- [Downloads and verification](release.md): choose, install and verify a published release.
- [Versions](versionado.md): what a release number and its source manifest mean.
