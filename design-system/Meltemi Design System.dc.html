Meltemi

El plano de control spec-driven para desarrollo agéntico. Este sistema cubre la superficie desktop (Tauri + Svelte) y el compañero móvil de control remoto, con los mismos tokens y el mismo vocabulario de estado que la TUI.

03

Identidad de flota

Fleet identity fleet-registry.toml

Diez entradas en el registro embebido. Meltemi no puede usar los logos de terceros, así que cada agente recibe un avatar de iniciales con un par de color propio: fondo desaturado al ~18 % de luminosidad, texto tintado al ~80 %. Los tonos están repartidos por el círculo cromático para que dos agentes nunca se confundan en una tabla densa, y el par cumple AA sobre su propio fondo. El nivel de integración se lee como texto (N1…N4), nunca como color.

09

Movimiento

Motion
120–160 ms, ease-out
Solo opacidad y transform. Nada de animar layout, alto o ancho.
reduced-motion
Suprime toda animación no esencial. Los spinners se vuelven glifo estático con la etiqueta textual «trabajando…».
Excepción absoluta
La bandeja de permisos y los banners de señal no animan su layout jamás: nada debe moverse bajo el cursor cuando decides un permiso.
Presupuesto CSS cross-webview
WebView2, WKWebView y WebKitGTK. Flexbox, grid, custom properties, :focus-visible, prefers-*. Fuera: backdrop-filter como efecto que carga peso, subgrid, animaciones por scroll.
